Anegudde Inventory System - Super Admin Manual

Overview
Full system access. You can manage all modules, users, roles, privileges, settings, and data.

Modules Accessible:
1. Home Dashboard - Overview of stock, low-stock alerts, daily summaries
2. Canteen Module - Purchases, Daily Usage, Wastages, Donations, Items, Categories, Menu Items, Vendors, Purchase Returns, Devotees
3. Reports - Stock Summary, Purchase Report, Canteen Summary, Manpower, Donation Report, Token Report
4. Users Management - Create/Edit users, manage roles, assign privileges, view activity logs
5. System Settings - Temple Identity, Receipt Settings, Printer Settings, Data Cleanup, Units, Donation Types
6. Profile - View/Edit personal profile

Key Actions:
- Full CRUD on all modules
- Assign/revoke privileges for any role
- Manage financial year rollover
- Configure temple identity and receipt settings
- View activity audit logs
