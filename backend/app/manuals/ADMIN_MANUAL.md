Anegudde Inventory System - Admin Manual

Overview
Full operational access to all modules except user/role privilege management.

Modules Accessible:
1. Home Dashboard - Overview of stock, low-stock alerts, daily summaries
2. Canteen Module - Purchases, Daily Usage, Wastages, Donations, Items, Categories, Menu Items, Vendors, Purchase Returns, Devotees
3. Reports - Stock Summary, Purchase Report, Canteen Summary, Manpower, Donation Report, Token Report
4. System Settings - Temple Identity, Receipt Settings, Printer Settings, Units, Donation Types
5. Profile - View/Edit personal profile

Key Actions:
- Manage all canteen transactions (purchases, usage, wastages, donations)
- Manage master data (items, vendors, categories, menu items)
- Generate and export reports
- Configure temple settings
- Monitor daily operations
