Anegudde Inventory System - Canteen Manager Manual

Overview
Full access to the Canteen Module for managing daily canteen operations.

Modules Accessible:
1. Canteen Dashboard - Daily canteen overview and summaries
2. Purchases - Add new stock purchases from vendors
3. Purchase Returns - Handle returns of purchased items
4. Daily Usage - Record stock consumption/usage
5. Wastages - Record expired/spoiled/damaged items
6. Donations - Record in-kind donations from devotees
7. Items - Manage raw items inventory
8. Item Categories - Manage item categorization
9. Menu Items - Manage canteen menu items
10. Vendors - Maintain vendor database with contacts
11. Devotees - View devotee records
12. Reports - Stock Summary, Canteen Summary, Purchase Report, Manpower Report, Donation Report, Token Report

Key Actions:
- Create/Edit/View purchases from vendors
- Record daily stock usage and wastages
- Record donations from devotees
- Manage items, categories, menu items, and vendors
- Generate and export canteen reports
- Monitor stock levels and low-stock alerts
- View token reports
