Anegudde Inventory System - Canteen Supervisor Manual

Overview
Limited operational access to the Canteen Module for daily transaction recording.

Modules Accessible:
1. Canteen Dashboard - Daily canteen overview
2. Daily Usage - Record stock consumption for the day
3. Wastages - Record expired/spoiled/damaged items
4. Donations - Record in-kind donations from devotees
5. Items - View raw items inventory
6. Reports - View Stock Summary and Canteen Summary

Key Actions:
- Record daily stock usage/consumption
- Record wastages
- Record donations from devotees
- View inventory items and stock levels
- View basic canteen reports
