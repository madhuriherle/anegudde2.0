Anegudde Inventory and Reporting System - User Manual

1. Introduction
The Anegudde Inventory System is a centralized platform for managing temple stock, canteen consumption, donations, and financial reporting. This manual covers the web interface used by administrators and office staff.

2. Dashboard and Navigation
- Main Dashboard: Provides a bird's-eye view of current stock levels, low-stock alerts, and daily transaction summaries.
- Sidebar Navigation: 
    - Main Menu: General settings and user profile.
    - Canteen Module: Access to daily transactions (Purchases, Usage, Wastages).
    - Reports: Comprehensive data analytics and exports.

3. Inventory Management (Masters)
Before recording transactions, ensure your Masters are correctly set up:
- Items: Add new items (e.g., Rice, Jaggery, Oil). Set their base unit and status.
- Item Categories: Group items (e.g., Grocery, Vegetables, Cleaning Supplies).
- Vendors: Maintain a database of suppliers with contact details and opening balances.
- Units: Define measurement units (Kg, Ltr, Pkt).

4. Daily Transactions
4.1 Purchases
Use this screen to add stock when goods are received from a vendor.
1. Select the Vendor.
2. Add Items, their Quantity, and Rate.
3. Click Submit to update the stock ledger instantly.

4.2 Daily Usage (Consumption)
Record how much stock is used by the temple canteen or for special events.
- Supports Real-time stock deduction.
- Option to track Manpower (staff/labor) associated with the usage.

4.3 Wastages
Record any items that have expired, spoiled, or were damaged. This ensures the physical stock matches the digital records.

5. Reporting System (SSRS Equivalent)
The system features a robust reporting engine similar to SSRS (SQL Server Reporting Services).
- Stock Summary:
    - Opening Balance: Stock available at the start of the period.
    - Purchases/Issues: Detailed breakdown of movement during the period.
    - Closing Balance: Current physical stock calculated automatically.
- Donation Reports: Track all in-kind donations with filters for Devotee Name, Date, and Item.
- Purchase and Usage History: Auditable trail of every transaction made in the system.

6. System Settings and Administration
- Temple Identity: Update the temple logo, subtitle, and address that appear on printed receipts.
- Financial Year Management: The system automatically handles FY rollover (April 1st), but you can view historical data by switching the FY view in the header.
- User Privileges: Granular control over who can Read, Create, or Edit specific modules.
