Anegudde Meal Token System - User Manual (Desktop App)

This manual provides a visual guide for operating the Token Desktop Application.

1. Login Screen
When you launch the application, you will see the Login screen. Use the credentials provided by the temple administrator.

(Refer to Image: Screenshot 2026-06-15 121115.png)

- Username: Enter your assigned username.
- Password: Enter your password.
- Settings: The gear icon in the top right is for initial setup (Admin only).

2. API Configuration (Setup)
If the system cannot reach the server, the Administrator must configure the connection.

(Refer to Image: Screenshot 2026-06-15 121138.png)

1. Click the Gear Icon on the login screen.
2. Enter the Master Password: d-apps@settings
3. Enter the correct Server API Base URL.
4. Click TEST CONNECTION and then SAVE and APPLY.

3. Dashboard Overview
Once logged in, you will see the main dashboard. This screen shows the live status for the current day.

(Refer to Image: Screenshot 2026-06-15 121204.png)

- TOTAL RECEIPTS: Shows how many times you have printed tokens today.
- TOTAL DEVOTEES: Shows the total number of people served today.

4. Issuing a New Token
This is the primary task for the operator.

(Refer to Image: Screenshot 2026-06-15 121217.png)

1. Enter Number: Type the number of devotees into the box under "NUMBER OF DEVOTEES".
2. Generate: Press ENTER on your keyboard or click the GENERATE and PRINT button.

5. Printing and Confirmation
After clicking Generate, the system will communicate with the printer and the server.

(Refer to Image: Screenshot 2026-06-15 121234.png)

- A loading spinner will appear briefly.
- The printer will automatically output the receipt.
- The dashboard counts (Receipts/Devotees) will update instantly.

6. Successful Completion
The system is designed for "rapid fire" entry. After one token is issued, the cursor automatically returns to the number box for the next devotee.

(Refer to Image: Screenshot 2026-06-15 121250.png)

- Verify the updated totals at the top of the screen to ensure the transaction was recorded correctly.

Quick Shortcuts
- ENTER Key: Prints the token immediately.
- ALT + F4: Closes the application.
- Logout: Click your name in the top right to sign out.
